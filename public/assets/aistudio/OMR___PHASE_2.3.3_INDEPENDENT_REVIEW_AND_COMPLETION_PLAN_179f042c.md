## 3. Mathematical Assessment of Property F

Отражение имеет определитель −1, поэтому для грани, **все** вершины которой отражаются, `A' = −A` точно, а `|A'| = |A|`. Это верно для любой невырожденной грани (включая невыпуклую), если порядок вершин сохранён.

| Случай | Корректная семантика | Что в тестах |
| --- | --- | --- |
| Полностью подвижная, невырожденная | Знак меняется, модуль сохраняется | Проверено в F1, F2, F3 (допуск `1e-12·max(1,\|A\|)`) |
| Полностью неподвижная | Площадь не меняется (тривиально, не свойство отражения) | F2: `\|A1−A0\| ≤ 1e-12` |
| Смешанная | Свойство **не применимо**: часть вершин сдвинута, часть нет | F2: проверено только, что обе площади ≠ 0 |
| Вырожденная (`\|A\|` ≈ 0) | Знак не определён: **не вычислимо**, не нарушение | F1: счётчик; F3: `isFaceDegenerate` |
| Поворот на 180° | Расстояния сохраняет, знак площади — нет | Проверено численно в последнем тесте |

Четыре исхода из задания (valid / not applicable / not evaluable / violation) в тестах **не различаются кодом**. Различает их только L7 — частично (см. раздел 5).

## 4. Review of NC-F1, NC-F2, NC-F3

**NC-F1 (подмена знака через реальный предикат) — не закрыт.** Предиката Property F в тестах нет. «Подмена знака» — это `Math.abs(a1Expected − a0) > 0.1`, то есть проверка, что площадь после отражения отличается от исходной. Это арифметика над двумя числами, а не отказ предиката на подделке. Координатная мутация через L7 (`FAIL`) — полезна, но это контроль L7, а не Property F.

**NC-F2 (явная классификация MIXED\_NOT\_APPLICABLE) — не закрыт.** Переменная `mixedOut` вычисляется и нигде не используется. Утверждение `isMixed` проверяет булево выражение, которое тест сам только что построил; перечисления или статуса `NOT_APPLICABLE` нет, есть комментарий «bypassed / marked NOT APPLICABLE». Негативный контроль «принудительное применение F к смешанной грани даёт ложное нарушение» отсутствует.

**NC-F3 (явная классификация DEGENERATE\_NOT\_EVALUATED) — закрыт частично.** Улучшение реальное: вырожденная грань теперь проходит через `reflectAcrossLine`. Но (а) вершины `D0,D1,D2` лежат **на оси** `y=x`, поэтому отражение их не сдвигает, и «вырожденность после отражения» истинна тривиально; (б) `verifyResult` для этого сценария не вызывается, поэтому статус `UNDETERMINED` не проверяется; (в) в негативном контроле проверяется только вспомогательная функция на вручную собранном состоянии.

**Контроль D vs F (поворот на 180°) — закрыт, с оговоркой.** Поворот вокруг (0.5, 0.5) сохраняет все попарные расстояния (`checkPairwiseDistances` → 0 нарушений) и сохраняет знак площади, чего Property F для отражения не допускает. Это настоящий и содержательный контроль. Оговорка: он идёт через `computeSignedArea`, а не через предикат (которого нет).

## 5. Property F vs Metric Property D

Независимость F от D доказана численно: D выдаёт PASS для обоих преобразований, F отличает отражение от поворота. Я воспроизвёл это отдельно на единичном квадрате: площадь до = 1, после отражения = −1, после поворота = +1, диагональ 1.4142… во всех трёх случаях.

**Что L7 фактически возвращает (мой пробный запуск `verifyResult`, не часть репозитория):**

| Сценарий | status | axioms | orientationInverted |
| --- | --- | --- | --- |
| Полное честное отражение | PASS | true | true |
| Смешанная грань (двигается только `V3`) | PASS | true | **true (вакуозно)** |
| Поворот 180°, заявленный как отражение | FAIL | **false** | false |
| Одна подвижная вырожденная грань | **UNDETERMINED** | true | false |
| Вырожденная + невырожденная подвижные грани | PASS | true | true |
| Микрогеометрия: треугольник с катетами 1e-6 и 2e-6 (площадь 1e-12) | **UNDETERMINED** («collinear vertices») | true | false |

Выводы: (1) L7 уже различает FAIL / UNDETERMINED / PASS, а смешанные грани пропускает; (2) у L7 нет статуса NOT\_APPLICABLE, смешанная грань даёт `orientationInverted = true` вакуозно; (3) при подделке «поворот вместо отражения» срабатывает и предикат осей, поэтому `orientationInverted` через публичный API в изоляции от `axiomsSatisfied` не показать.

## 6. Remaining Defects and Risks

1. **D1 (тесты).** Нет предиката и классификации Property F; NC-F1/NC-F2 доказывают меньше, чем утверждают названия.
2. **D2 (тесты).** Метаморфные тесты не проверяют `predicates.orientationInverted` и статус `UNDETERMINED`, хотя L7 реализует оба.
3. **D3 (тесты).** Сценарий вырожденной грани лежит на оси: тривиален.
4. **D4 (согласованность порогов).** Тест: `\|A\| < 1e-12`; L7: `\|A\| <= 1e-12`. Расхождение на границе. Допуски площади тоже различаются (тест `1e-12`, L7 `1e-7`) — приемлемо (тест строже), но не задокументировано.
5. **D5 (отчёт).** Фраза «полностью устранены» неверна; кроме того, отчёт приводит `index-Bxb71WAQ.js 562.64 kB`, а у меня получился `index-C6zy7yjT.js 335.25 kB`. Расхождение не объяснено (возможно, различие окружений); без `.git` его нельзя проверить.
6. **R1 (риск, не дефект Phase 2.3.3).** Абсолютный порог `1e-12` не масштабно-независим: настоящий микротреугольник с площадью 1e-12 классифицируется как коллинеарный и даёт `UNDETERMINED`. Относится к D3–D6, в эту фазу не входит.
