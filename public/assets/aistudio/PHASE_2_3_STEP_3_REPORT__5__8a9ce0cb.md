## 1. Что реализовано (R1–R7)

**R1. Независимый классификатор** `classifyPropertyF` (тестовый код). Использует собственную формулу шнуровки и разбиение вершин на moving/fixed; предикаты L7 не читает. Порог вырожденности — `DEFAULT_VERIFIER_TOLERANCES.degenerateAreaEpsilon`, оператор `<=`, как в L7. Исходы: `HOLDS`, `VIOLATION`, `FIXED_UNCHANGED`, `FIXED_CHANGED`, `MIXED_NOT_APPLICABLE`, `DEGENERATE_NOT_EVALUATED`. Граничный тест: треугольник с `|A|` ровно на пороге (проверено `assert.equal`) → вырожденный и в классификаторе, и в `isFaceDegenerate`, и в L7 (`UNDETERMINED`); чуть ниже → то же; на 1e-6 выше → `HOLDS` и L7 `PASS`.

**R2. Классификация сценариев.** F1: все 8 комбинаций «геометрия × ось» → каждая грань `HOLDS` (точный счёт: 4·2 + 4·3 = 20 `HOLDS`, остальные классы 0). F2: `F_MOVING` → `HOLDS`, `F_FIXED` → `FIXED_UNCHANGED`, `F_MIXED` → `MIXED_NOT_APPLICABLE`. F3: невырожденная грань с вершиной на оси → `HOLDS`. Все ожидания проверяются исполняемыми `assert`, не комментариями.

**R3. NC-F1.** Настоящий поворот на 180° вокруг (0.5, 0.5): проверено, что каждая вершина переходит в точечно-симметричную, не равную исходной. Попарные расстояния сохранены (6 пар, 0 нарушений), знак площади сохранён; классификатор → `VIOLATION` на обеих гранях. L7 для поворота, выданного за отражение, с допусками по умолчанию: `status = FAIL`, `lengthsPreserved = true`, `areaPreserved = true`, `orientationInverted = false`, `axiomsSatisfied = false`. **Предикат ориентации изолируется через публичный `overrides`:** при `{ epsilon: 10, areaEpsilon: 1e-7 }` аксиомы, привязка свидетельства, длины и площади проходят, и `FAIL` остаётся только из-за `orientationInverted = false`. (Прежняя редакция этого отчёта утверждала обратное; это было ошибкой.) Подделка получает `stateId`/`version` честного результата, иначе привязка свидетельства рушится по тривиальной причине. Отдельно: мутация координаты → `VIOLATION` только на затронутой грани, L7 `FAIL` (в том числе с подделанными `claimedResiduals = 0`).

**R4. NC-F3.** Коллинеарная подвижная грань лежит на `y = x + 1`, ось `x = 10`; вершины вне оси и реально смещаются. После отражения грань вырождена; классификатор → `DEGENERATE_NOT_EVALUATED` (проверено, что не `HOLDS` и не `VIOLATION`); L7 → `UNDETERMINED`, `orientationInverted = false`, `axiomsSatisfied = true`. Сценарий «вырожденная + невырожденная подвижные грани»: классификатор по граням `DEGENERATE_NOT_EVALUATED` / `HOLDS`, L7 `PASS`, `orientationInverted = true`.

**R5. NC-F2.** Смешанная грань `B,D,G,C`: классификатор → `MIXED_NOT_APPLICABLE`. Наивное применение `A(R(F)) = −A(F)` даёт ошибку знака и модуля > 1e-3 (ложное нарушение). L7 в целом → `PASS`. Дополнительно характеризационный тест: если все грани смешанные, L7 `PASS` с `orientationInverted = true` — **вакуозно** (у L7 нет статуса NOT_APPLICABLE, предикат остаётся значением по умолчанию).

**R6. Эти проверки L7 не заменяют классификатор и стоят рядом с ним.
