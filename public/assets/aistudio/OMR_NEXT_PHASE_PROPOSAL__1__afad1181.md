Строить цепочки операций поверх верификатора с неочерченной областью надёжности рискованнее, чем сначала её очертить.

## 3. Варианты порога вырожденности (задача 2)

| Вариант | Суть | Последствия |
|---|---|---|
| **a. Оставить абсолютный 1e-12** | Задокументировать область: грани с линейным размером ≳ 1.5e-6 | Нарушает масштабную инвариантность: подобные фигуры получают разные вердикты. Ничего не ломает |
| **b. Относительно масштаба грани**: `\|A\| <= c · L²`, L — наибольшая длина ребра | Подобные фигуры получают один вердикт; настоящие микротреугольники проходят. Тонкие треугольники с `\|A\|/L² < c` становятся «вырожденными» — нужен выбор `c` (порядок 1e-9…1e-6) и обоснование | Меняет границу `UNDETERMINED`; характеризационный тест D-2 и граничный тест R1 нужно переписать |
| **c. b плюс нижняя граница шума**: `max(c·L², k·ε_маш·Σ\|члены\|)` | Учитывает потерю точности шнуровки; при центрировании (задача 1) шум мал | Сложнее; нужны тесты на тонкие и далёкие от начала грани |

Моё мнение (не решение): b вместе с задачей 1; выбор `c` — по результатам D3–D6, а не заранее. Порог 1e-12 заменять автоматически не следует.

## 4. Риски

1. Любое изменение L7 сдвигает границы вердиктов; существующие 47 тестов частично закрепляют текущее поведение.
2. Выбор `c` без данных. Нужен эксперимент D6 (тонкие треугольники, aspect ≈ 1e4).
3. Расширение области (большие координаты) не доказывает математическую верность — только пределы доверия числам.

## 5. Критерии приёмки

1. Для смещений до 1e9 и катетов до 1e-9: верное отражение даёт `PASS`, подделанный поворот — `FAIL` с `orientationInverted = false` (изолированно), вырожденная грань — `UNDETERMINED`; подобные фигуры в разных масштабах — одинаковые вердикты.
2. Все 47 тестов проходят или переписаны сознательно; каждое переписанное — перечислено с причиной.
3. Мутации критических веток нового порога ловятся.
4. `npm ci`, `npm test`, `npm run lint`, `npm run build` — без ошибок; `dist/` без утечек.
5. Документы согласованы: README, структура, отчёт фазы.
6. Явный список того, что не проверено; заявления не шире протестированной области.
