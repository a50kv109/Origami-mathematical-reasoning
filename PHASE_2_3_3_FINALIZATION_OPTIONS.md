## 1. Ответы на 7 контрольных вопросов завершения Phase 2.3.3

1. **Какие части кандидатной версии можно восстановить достоверно?**
   - Архитектурно-доказательную модель (`classifyPropertyF` на 6 исходов, порог `<= degenerateAreaEpsilon`, правила `FIXED_UNCHANGED` vs `FIXED_CHANGED`, механизм изоляции `L7.orientationInverted` через `{ epsilon: 10, areaEpsilon: 1e-7 }`, постановку характеризационных тестов `D-1`, `D-2`, `F2 all-mixed`), а также перечень `32` неизменяемых базовых тестов (`19` `contract02` + `13` A–E из текущей базы) `[S][D]`.
   - **Нельзя** восстановить достоверно: побайтовый текст кандидатного `tests/metamorphic.test.ts` (имена всех `15` новых блоков `test(...)`, точные координаты фикстур `R1` на границе `1e-12`, невыпуклого 5-угольника, формулу центрирования внутри тестового оракула и точную сетку сдвигов `D-1`/`D-2`) `[E][D]`.

2. **Какие изменения можно перенести без оригинального кандидатного файла?**
   - **Никаких кодовых изменений из кандидатной ветки переносить без оригинала нельзя** — в AI Studio физически отсутствуют как `tests/metamorphic.test.ts` (`candidate/phase-2-3-3-rework`), так и `L7_CENTERED_AREA_PROPOSAL.patch` `[E]`. Единственное, что можно подготовить без оригинала — исследовательские документы и манифесты (что и выполнено), а также при отдельном разрешении владельца — гигиену архивирования 17 вложений из `public/assets/aistudio/` `[P]`.

3. **Какие сведения являются только описаниями (`[DESCRIPTION]`)?**
   - Существование и прогон `47/47` тестов в ветке `candidate/phase-2-3-3-rework`;

   - результаты `16/17` ручных мутаций;

4. **Какие тесты можно заново реализовать на основании однозначной спецификации, не выдавая их за оригинальные?**
   - При наличии письменного решения владельца выбрать путь **повторной реализации** (если ветка Claude окажется недоступна), по спецификации `PHASE_2_3_3_PROPERTY_F_SPECIFICATION.md` можно однозначно реализовать с нуля (с маркировкой `[RECONSTRUCTED]`, не выдавая за `candidate/phase-2-3-3-rework`): `classifyPropertyF` (6 исходов, порог `<= 1e-12`), тест границы `|A| == 1e-12`, `F1`/`F2`/`F3`, `F2 (all-mixed characterization)`, невыпуклый 5-угольник CCW/CW, `NC-F1` (поворот 180° + согласованная подделка + изоляция L7 через `{epsilon:10, areaEpsilon:1e-7}`), `NC-F2`, `NC-F3` (вне оси `y=x+1`, ось `x=10` + пара с невырожденной), `FIXED_CHANGED` (сдвиг вершины и перенос `(0.5, 0.25)`), край допуска (`1e-14/1e-9/1e-5`) и характеризацию `D-1`/`D-2` `[M][D][P]`.

   - `npm run lint` (`tsc --noEmit` со `"strict": true`) → код возврата `0`;
