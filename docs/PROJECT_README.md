# Origami Mathematical Reasoning (OMR)

**Тип системы:** исследовательско-инженерное математическое ядро и инфраструктура Zero-Trust верификации.  
**Текущая версия и статус:** `v0.1.0` — **Phase 2.1 (Verified 2D Reflection Prototype)**; реализован и покрыт тестами контракт `Contract 02 v2` (`L2 ↔ L7` для `REFLECTION_ACROSS_LINE`).  
**Репозиторий:** <https://github.com/a50kv109/Origami-mathematical-reasoning>  
**Лицензия:** [Apache-2.0](../LICENSE)

## 1. Назначение проекта

**Origami Mathematical Reasoning (OMR)** — это **не** графический редактор, **не** физический симулятор и на этапе `v0.1.0` **не** полноценная система физического складывания оригами. Это математическое ядро и архитектура верификации, предназначенные для того, чтобы отделить формальное математическое рассуждение от генерации планов ИИ-агентами и внешних программ проектирования:

1. Интерпретировать и представлять геометрический объект в строго типизированной форме (`GeometryState`).
2. Выполнять детерминированные математические преобразования с проверкой предусловий (`L2`, в `v0.1.0` — `REFLECTION_ACROSS_LINE`) и выпуском свидетельства (`ReflectionWitness`).
3. Фиксировать воспроизводимую и глубоко замороженную историю переходов (`TRACE`).
4. Независимо проверять корректность как результата (`Result Verification`), так и процесса (`Process Verification`) в изолированном слое `L7` по принципу **Zero-Trust**.
5. В перспективе (после `v0.1.0`) подключать внешние программы проектирования оригами через стандартизованный адаптерный слой (`Tool Integration Layer`).

Оригами выступает первой экспериментальной средой для формализации перехода от плоской 2D-геометрии к пространственным конструкциям и переносимой математической компетенции для смежных инженерных областей.

## 2. Три разделённых контура системы

| Контур | Назначение | Статус в `v0.1.0` и граница ответственности |
| :--- | :--- | :--- |
| **A. Origami Reasoning Core** | Математическое ядро (`L1–L7`, `STATE`, `TRANSFORMATION`, `TRACE`, `VERIFICATION`) | **Реализованы `L2` (2D-отражение), `TRACE` и аксиоматический `L7`** в `src/core/`. `L1`, `L3–L6` находятся в стадии проектирования/исследования. |
| **B. Origami Design Tools** | Внешние инструменты (`Ori Studio`, `Oriedita`, `Rabbit Ear`, `OrigamiSimulator`) | **Только спроектированы и проаудированы** (в `v0.1.0` адаптеры не реализованы; сторонний код исключён из репозитория). |
| **C. AI Agent Reasoning Skill** | Связующий контур рассуждения агента | **Запланирован (Phase 8);** агент не имеет права самостоятельно объявлять результат математически доказанным. |

Целевой поток взаимодействия:

```text
NATURAL LANGUAGE → REASONING → MATHEMATICAL MODEL → OPERATION PLAN
  → [CORE / TOOL ADAPTER] → RESULT + WITNESS → TRACE → INDEPENDENT VERIFICATION (L7)
```

---

## 3. Главный принцип

**Goal-Oriented Mathematical Verification:** математическая строгость должна обеспечивать правильность инженерного результата. Единственность последовательности построения не требуется: допускаются альтернативные траектории, если каждое состояние, свидетельство и переход удовлетворяют контрактам и инвариантам в `L7`.
