# First Prototype Specification — Спецификация первого прототипа (`L2 ↔ L7`)

**Цель прототипа:** подтвердить работу цикла **L2 (вычисление) → TRACE → L7 (Zero-Trust независимая проверка)** на простейшей ограниченной 2D-задаче без перехода к 3D-кинематике и физическим деформациям.

---

## 1. Границы применимости (Scope)

- **Входит в прототип:**
  - плоская 2D-геометрия нулевой толщины в `ℝ²`;
  - единичный квадрат `[0, 1] × [0, 1]` (`L = max(|x|, |y|) ≤ 2`);
  - две базовые операции: `FACE_SUBDIVISION` (по прямой `x + y = 1`) и `REFLECTION` (аффинное отражение треугольной грани);
  - журнал переходов `TRACE` (`S₀ → S₁ → S₂`);
  - независимый верификатор `L7` с режимами `Result Verification` и `Process Verification`.
- **Исключено (`OUT_OF_SCOPE → CAPABILITY_GAP`):**
  - 3D-координаты, двугранные углы и непрерывная кинематика `γ(t)`;
  - порядок перекрытия слоёв (`L3`) для 3+ слоёв;
  - толщина бумаги, упругость и криволинейные сгибы (`L5`).

---

## 2. Математическая постановка эталонного сценария (`square_reflection`)

1. **Начальное состояние `S₀`:** единичный квадрат с вершинами `V₀(0,0)`, `V₁(1,0)`, `V₂(1,1)`, `V₃(0,1)` и одной гранью `F₀` (площадь `1.0`).
2. **Подразделение `S₁` (`FACE_SUBDIVISION`):** рассечение по оси `x + y = 1` (проходящей через `V₃(0,1)` и `V₁(1,0)`). Образуются две треугольные грани:
   - `F₀_A = [V₀(0,0), V₁(1,0), V₃(0,1)]` (неподвижная);
   - `F₀_B = [V₃(0,1), V₂(1,1), V₁(1,0)]` (отражаемая), площадь каждой `0.5`.
3. **Отражение `S₂` (`REFLECTION`):** задаётся ось `a = (0, 1)`, единичный направляющий вектор `u = (1/√2, -1/√2)`. Матрица отражения:
   `R = 2 u uᵀ - I = [[0, -1], [-1, 0]]`, преобразование `p' = a + R (p - a) = (1 - y, 1 - x)`.
   Вершина `V₂(1,1)` переходит в `V₂'(0,0)`, вершины на оси `V₃(0,1)` и `V₁(1,0)` остаются инвариантными.

---

## 3. Протокол независимой проверки L7 (`Contract 02`)

Верификатор `L7` **не импортирует** функции расчёта из модуля `L2` и выполняет 5 независимых проверок:

1. **Axis Invariance:** проверка, что точки оси сгиба (`V₃`, `V₁`) сместились не более чем на `ε_axis = 1e-9`.
2. **Edge-Length Isometry:** пересчёт длин всех рёбер грани `F₀_B` до и после операции; `|ΔL| ≤ ε_coord` (`1e-7`).
3. **Area Preservation:** независимый пересчёт площади по формуле Гаусса (Shoelace); `|ΔS| ≤ ε_area` (`1e-9`).
4. **Orientation Inversion:** проверка смены знака ориентированной площади (детерминанта) при несобственной изометрии (отражении).
5. **Independent Recomputation:** пересчёт `p'_expected` по нормали к прямой `x + y - 1 = 0` и сравнение `‖p'_reported - p'_expected‖ ≤ ε_coord`.

Возвращаемые вердикты: `PASS` · `FAIL` (с указанием кода ошибки, например `INVARIANT_VIOLATION_ISOMETRY`) · `UNDETERMINED` · `CAPABILITY_GAP`.

---

## 4. Обязательный набор тестов прототипа (вкл. негативные контроли)

- **Positive Case (`T-01`):** точное отражение `F₀_B` по `x + y = 1` → вердикт `PASS`.
- **Negative Control — Corrupted Vertex (`T-02`):** генератор сдвигает `V₂'` в `(0.18, 0.08)` → L7 фиксирует нарушение изометрии и площади → `FAIL`.
- **Negative Control — Axis Drift (`T-03`):** смещена точка на оси сгиба → `AXIS_DISPLACEMENT_DETECTED` → `FAIL`.
- **Boundary Control (`T-04`):** запрос с 3D-углом сгиба или толщиной листа → `CAPABILITY_GAP` (не `FAIL` и не `PASS`).
